# CLAUDE.md

Spotify-пульт для часов на Zepp OS 3.6+ (целевые часы — Amazfit Active 3 Premium, круглый экран 480).
Пользовательское описание — в [README.md](README.md) / [README-ru.md](README-ru.md).

## Главное правило: каждое изменение — коммит и пуш

Разработка идёт из разных сессий, локальное состояние между ними не переносится.
- Любое законченное изменение (даже мелкое) сразу коммитится и пушится в `origin/main`.
- Перед началом работы: `git pull --ff-only`, в конце сессии `git status` должен быть чистым, а `main` — совпадать с `origin/main`.
- Перед коммитом — `npm run check` (сборка должна проходить).
- Коммиты: короткий заголовок на английском в повелительном наклонении («Add …», «Show …»), при необходимости — тело с пояснением.
- Незавершённую работу тоже не оставлять только локально: коммитить как WIP, а в конце этого файла, в разделе «Текущее состояние», писать, что осталось сделать.

## Окружение

- Node.js стоит в домашней папке без sudo: `~/.local/opt/node` (симлинки в `~/.local/bin`), npm `prefix=~/.local`, так что глобальные пакеты (`zeus`) тоже попадают в `~/.local/bin`.
- Если Node нет: скачать LTS-архив `linux-x64` с nodejs.org, проверить по `SHASUMS256.txt`, распаковать в `~/.local/opt`, затем `npm config set prefix ~/.local && npm i -g @zeppos/zeus-cli`.
- `npm i` — зависимости проекта (`@zeppos/zml`, типы устройств).
- Python 3 и ffmpeg есть в системе (нужны для `tools/*.py`).
- `gh` залогинен как iArti, пуш по https.

## Команды

| Команда | Что делает |
|---|---|
| `npm run check` | `zeus build` с временной заглушкой секретов, если `app-side/secrets.js` нет. Главная проверка перед коммитом |
| `npm run build` / `zeus build` | Сборка `.zab` в `dist/` (нужен настоящий `app-side/secrets.js`) |
| `npm run preview` / `zeus preview` | QR-код для установки на часы (нужен `zeus login`, интерактивно — делает пользователь) |
| `npm run auth -- <ID> <SECRET>` | Логин в Spotify, пишет `app-side/secrets.js` |
| `npm run assets` | Перерисовать иконки в `assets/common.r/` (`tools/make_assets.py`, без внешних зависимостей) |
| `python -I tools/import_covers.py <папка>` | Обложки для режима «Музыка с часов» в `assets/common.r/covers/` (gitignored) |

Автотестов нет. Проверка поведения — только на часах, это делает пользователь; в ответе явно говорить, что на устройстве не проверено.

## Устройство

- `app.js` — `BaseApp` (zml): `globalData` с последним состоянием плеера, приём файлов (обложки, миниатюры) с телефона, медиаплеер для локальной музыки.
- `app-side/index.js` — side service в приложении Zepp на телефоне: ходит в Spotify Web API (refresh token → access token), отвечает на запросы часов в `onRequest` по `req.method` (`state`, `pause`, `like`/`unlike`, `devices`, `transfer`, `queue`, `play_context`, `recent` …), шлёт обложки файлами.
- `page/*/index.js` — страницы (`BasePage`), общаются с телефоном через `this.request({ method, params }, { timeout })`:
  - `control` — заставка (обложка + часы) и экран управления, кнопки железа, жесты; самая большая страница;
  - `library` — Liked Songs и недавние плейлисты; `queue` — очередь/текущий плейлист; `devices` — выбор Spotify Connect устройства; `volume` — громкость.
- `shared/` — общий код часов: `ui.js` (виджеты, цвета), `config.js` (настройки пользователя, меняются и пересобираются), `local.js` + `id3.js` + `text.js` — режим «Музыка с часов», `files.js`/`thumbs.js` — приём файлов.
- Новые страницы регистрировать в `app.json` → `targets.common.module.page.pages`.

## Соглашения

- Интерфейс на часах — на русском; код, комментарии, коммиты — на английском.
- README ведутся на двух языках: меняешь `README.md` — обнови `README-ru.md` (и наоборот).
- `app-side/secrets.js` никогда не коммитить (он в `.gitignore`).
- Стиль кода: ES-модули, 2 пробела, двойные кавычки, точки с запятой, комментарии короткие и только там, где неочевидно.
- `shared/text.js` и `tools/import_covers.py` должны декодировать теги одинаково (ключи обложек — FNV-1a), менять синхронно.
