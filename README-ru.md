# zepp-better-spotify-remote

[English](README.md)

Пульт для Spotify на часах с Zepp OS. Сделан потому, что Music Controller из магазина каждый раз секунд пять пишет «загрузка», выглядит так себе и не умеет в кнопки. Этот открывается сразу (показывает последнее состояние, свежее подтягивает в фоне), на фоне обложка трека, сверху часы.

Экраны: скринсейвер (обложка, часы, тап — пауза, двойной тап слева/справа — назад/вперёд), управление (кольцо прогресса вокруг play, лайк, текущий плейлист, выбор устройства и громкость), свайп вверх — библиотека с «Любимыми треками» и недавними плейлистами. Пока играет музыка, экран не гаснет; на паузе гаснет через 3 минуты. Делал под себя и Amazfit Active 3 Premium, на других круглых часах с Zepp OS 3.6+ скорее всего тоже заведётся, но не проверял. Интерфейс на русском.

## Установка

Нужны Node.js, Spotify Premium (без него API не даёт управлять воспроизведением) и режим разработчика в приложении Zepp.

1. Создайте приложение на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard): тип **Web API**, Redirect URI ровно `http://127.0.0.1:8888/callback`. В настройках приложения возьмите Client ID и Client Secret.
2. Соберите ключи (откроется браузер, войдите в Spotify):
   ```bash
   npm i
   node tools/spotify-auth.mjs <CLIENT_ID> <CLIENT_SECRET>
   ```
   Скрипт запишет всё в `app-side/secrets.js`. Он в `.gitignore`, не коммитьте его.
3. Поставьте на часы:
   ```bash
   npm i -g @zeppos/zeus-cli
   zeus login
   zeus preview
   ```
   Выберите свои часы и отсканируйте QR-код в Zepp: Профиль → Developer Mode → Scan.

Носите часы на правой руке — поставьте `rightHandMode = true` в `shared/config.js` и пересоберите: Up — пауза, Down — следующий трек, Select — переключение экранов. Иконки рисует `tools/make_assets.py` (`python tools/make_assets.py`), если захотите поменять.

## Экспериментально: музыка с часов

Устройства → «Музыка с часов» играет треки, которые вы закинули на часы штатным приложением «Музыка» в Zepp, — в Bluetooth-наушники, без телефона. Кнопка текущего плейлиста превращается в список этих треков; порядок — `localSort` в `shared/config.js` (`"name"`, `"artist"` или `"album"`, нелатинские названия идут первыми).

Режим экспериментальный, потому что работает только благодаря недосмотру в песочнице файлов часов: приложение добирается до системной папки с музыкой через `data://../../../Downloads/Music/list`. Любое обновление прошивки может это прикрыть. Теги читаются прямо из файлов на часах.

Обложки — по желанию, и с ними возня: часы не умеют декодировать JPEG внутри MP3, поэтому обложки готовятся на ПК и вшиваются в приложение. Натравите скрипт на ту же папку, из которой закидываете музыку, и пересоберите:

```bash
python tools/import_covers.py "путь/к/музыке"
```

Нужен ffmpeg в PATH, результат — в `assets/common.r/covers/` (в `.gitignore`). Каждая обложка добавляет к установке ~30 КБ.

`applyOptimizations` в `shared/config.js` реже опрашивает Spotify на скринсейвере (15 с во время игры, 30 с на паузе) ради батареи. По умолчанию выключено: пауза и переключение треков с других устройств тогда видны с задержкой.

## По желанию: SimpleZepp для громкости телефона

Spotify не даёт менять громкость телефона через свой API. Если на том же телефоне стоит [SimpleZepp](https://github.com/iArti/SimpleZepp), на экране устройств появится строка «Подключить SimpleZepp»: тапните, разрешите запрос в уведомлении на телефоне — и громкость заработает и для Spotify на телефоне. Без SimpleZepp ничего не меняется.
